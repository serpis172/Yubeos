# ADR-0010: Linux accounts via PAM, server-side sessions, TOTP

**Status:** Accepted · **Date:** 2026-11-11

## Context
A NAS should not introduce a second user database; file permissions and SMB users map to Linux users.

## Decision
Authenticate with PAM inside `yubeos-priv`; authorise via groups (`yubeos-admin`, `yubeos-user`); opaque server-side sessions in a `__Host-` cookie with CSRF header; optional/enforceable TOTP; hashed scoped API tokens; step-up re-auth for destructive operations.

## Consequences
Consistent identity and permissions; depends on PAM config; no SSO in 1.0 (OIDC is post-1.0).

## Alternatives considered
Own user DB: duplicates identity, drift with Samba/ACLs. JWT sessions: revocation complexity.
